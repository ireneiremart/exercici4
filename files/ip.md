# Módulo que más me gusta

El módulo que más me gusta es **Implantación de Aplicaciones Web**.

## ¿Por qué?

Me gusta porque aprendemos cosas que podemos aplicar de forma práctica, como:

- Git y GitHub
- Servidores
- Aplicaciones web
- Trabajo con repositorios

Además, me parece *interesante* aprender a trabajar con herramientas que se utilizan realmente en informática.

> Creo que es un módulo útil para aprender a trabajar en proyectos reales.

Puedes encontrar más información sobre GitHub en [GitHub](https://github.com).
